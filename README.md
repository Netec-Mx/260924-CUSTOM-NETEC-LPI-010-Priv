# Linux Essentials

Este programa de capacitación está diseñado para ingenieros y administradores de sistemas que desean llevar sus habilidades al siguiente nivel. A lo largo de sus cuatro capítulos, el curso combina bases teóricas rigurosas con una sólida práctica intensiva para dominar la gestión de infraestructuras Linux robustas, seguras y altamente disponibles.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [Laboratorio 7: Creación de un Servicio Persistente, Seguro y Monitoreado tras un Boot Personalizado](Capitulo01/README.md#laboratorio-7-creación-de-un-servicio-persistente-seguro-y-monitoreado-tras-un-boot-personalizado)
  - Descripción: Creación de un servicio persistente, seguro y monitoreado tras un boot personalizado, integrando daemons, systemd, administración remota, monitoreo, kernel, particiones, sistemas de archivos y proceso de boot.
  - Duración estimada: 223 min

### Capítulo 2

- [Laboratorio 8: Rescate de un Servidor Inundado de Logs y con Boot Corrupto](Capitulo02/README.md#laboratorio-8-rescate-de-un-servidor-inundado-de-logs-y-con-boot-corrupto)
  - Descripción: Rescate de un servidor inundado de logs y con boot corrupto mediante el análisis de logs del sistema, la detección de fallas y el diagnóstico de issues comunes del sistema operativo.
  - Duración estimada: 131 min

### Capítulo 3

- [Laboratorio 9: Automatización de Red e Infraestructura de Contenedores mediante YAML](Capitulo03/README.md#laboratorio-9-automatización-de-red-e-infraestructura-de-contenedores-mediante-yaml)
  - Descripción: Automatización de red e infraestructura de contenedores mediante YAML, utilizando políticas del sistema en distribuciones Ubuntu y el modelado de configuraciones con archivos YAML/YML.
  - Duración estimada: 123 min

### Capítulo 4

- [Laboratorio 10: Despliegue Multi-Entorno y Recuperación ante Caídas de X11/Wayland](Capitulo04/README.md#laboratorio-10-despliegue-multi-entorno-y-recuperación-ante-caídas-de-x11wayland)
  - Descripción: Despliegue multi-entorno y recuperación ante caídas de X11/Wayland, aplicando la arquitectura del entorno gráfico en Linux y la comparación práctica de entornos de escritorio.
  - Duración estimada: 123 min
